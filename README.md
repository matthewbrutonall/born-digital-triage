# Born-Digital Triage skill

An agent guide for carrying out a safe first review of born-digital file listings.

It helps an agent:

- explain what archival triage means;
- identify files that may need earlier review;
- distinguish supplied facts from filename and folder signals;
- record missing information and sensible next checks; and
- avoid turning preliminary signals into preservation or disposal decisions.

The skill can guide an ordinary triage directly. It contains no executable helper and does not require another tool.

For large listings, repeatable directory inventories, or saved CSV, Markdown and JSON reports, a separate optional CLI is available:

https://github.com/matthewbrutonall/born-digital-triage-cli

The skill and CLI are independent. Neither inspects file contents, follows symbolic links, or performs deletion, migration, deduplication or repository ingest.
